ChessBot: Automated 3-Axis Chess-Playing Robot

Problem Statement

The objective of this technical exercise was to build an automated system capable of playing chess against a human opponent while physically interacting with the chessboard. The core engineering challenge lay in bridging the gap between abstract game logic and physical actuation—specifically, enabling a Cartesian robot to accurately pick up, move, and remove pieces without human intervention.

Proposed Solution

I developed a comprehensive hardware-software architecture using a Siemens PLC to coordinate three stepper motors via the PROFINET protocol. The cognitive "brain" of the system is the Sunfish chess engine running in Python, which validates the player's moves and calculates the machine's response. Communication between the Python engine and the Siemens PLC is achieved through the OPC UA protocol. To complete the system, I designed a retro-1980s inspired HMI panel in TIA Portal, providing users with an intuitive interface to input their moves and control the system.

Key Results

  1. Successfully designed and deployed a complete IT/OT integration project, connecting high-level Python logic with low-level Siemens hardware.
  2. Engineered precise electromechanical control for a 3-axis robotic system equipped with a DH-ROBOTICS electric gripper to handle chess pieces.
  3. Developed a fully functional, user-friendly HMI that accurately maps chessboard coordinates, handles invalid move validation, and manages the homing routine.
