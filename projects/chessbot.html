ChessBot: Automated 3-Axis Chess-Playing Robot

Problem Statement

The objective of this technical exercise was to build an automated system capable of playing chess against a human opponent while physically interacting with the chessboard. The main engineering challenge was to bridge the gap between abstract game logic and physical actuation, enabling a Cartesian robot to accurately pick up, move, and remove pieces without human intervention.

Proposed Solution

I developed a comprehensive hardware-software architecture using a Siemens S7-1500 PLC to coordinate three stepper motors via PROFINET. The system's cognitive core is the Sunfish chess engine, implemented in Python, which validates human moves and calculates the robot's responses. Communication between the Python engine and the Siemens S7-1500 PLC is handled via OPC UA. To complete the system, I designed a retro-1980s-inspired HMI panel in TIA Portal, providing an intuitive interface for entering moves and controlling the robot.

Key Results

  1. Designed and deployed a complete IT/OT integration project, connecting high-level Python logic with Siemens S7-1500 PLC hardware.
  2. Engineered precise electromechanical control for a 3-axis Cartesian robotic system equipped with a DH-ROBOTICS electric gripper to handle chess pieces.
  3. Developed a functional, user-friendly HMI that maps chessboard coordinates, validates moves, handles invalid inputs, and manages the homing routine.
