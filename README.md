# Nicolò Girardello - Personal Portfolio

Personal portfolio website of **Nicolò Girardello**, MSc Student in Control Systems Engineering at the University of Padua. 
This repository hosts a showcase of academic, personal, and competition projects spanning robotics, automation, control systems, and machine learning.

**Live Demo:** [girardellon.github.io](https://girardellon.github.io/)

## Tech Stack
- **HTML5**
- **CSS3** (Custom properties, Flexbox/Grid)
- **Vanilla JavaScript** (DOM manipulation, interactive timeline)
- Hosted on **GitHub Pages**

## Structure
- `index.html` - Homepage featuring a dynamic timeline and selected works.
- `education.html` - Academic background and international experiences.
- `projects.html` - Complete catalog of projects.
- `projects/` - Detailed pages for individual projects (e.g., BSc Thesis, Robotics applications).
- `contact.html` - Professional links and contact information.
- `assets/` - CSS stylesheets, images, and documentation.
